How it's built

The data

Box scores from ESPN. Each team's recent form is tracked with exponentially weighted averages (points, shooting, rebounds, assists, turnovers), plus rest days, home/away record and the opponent's defense.

The model

A random forest predicts each team's score. It retrains every morning, with this season's games weighted more heavily. Every remaining game is re-predicted from each team's latest form.

The odds

Win probabilities treat the final margin as normally distributed around the predicted margin, with spread measured on held-out games. Key injuries (15+ PPG) lower a team's predicted score.
